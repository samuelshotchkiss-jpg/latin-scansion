# Derivatives: team race — the spec (owner's rulings, 2026-11-04)

A Latin I version of the derivatives game (`live/modes/derivatives.js`, "Derivatives: class relay", which
Latin II played and liked). Read that file first, then `live/modes/devices.js`: this mode is the
derivatives *cards* in the devices mode's *team race*. Read `live/MODES.md` for the shell.

## 1 · What the owner asked for, and ruled

- **The class:** Latin I, 8 students, eighth grade and up, with English learners in their first year
  abroad. Two teams of four, racing each other. With absences: 7 → 4+3, 6 → 3+3, **5 → 3+2 is allowed**.
- **The cards:** the same four as the relay — Latin word, Latin meaning, English derivative, English
  meaning. One is the team's prompt; the team finds the other three.
- **The race:** both teams get **the same words, in the same order, with the same prompt card kind**
  (a fair race). Teams move at their own pace. **The first team to finish every word wins.**
- **A wrong card freezes the whole team for 5 seconds** (setting: 0 / 3 / 5 / 8; default 5). Every
  device on that team is locked, with a countdown, and the projector shows the freeze. No time is added.
- **Word sets:** `data/derivatives.json` now holds `ii04` (Latin II), `i04` (Latin I · Trial 4, 13 words)
  and `i0304` (Latin I · Trials 3–4, 23 words). It is GENERATED by the toolkit — never edit it by hand.

## 2 · The mode

- id `derivrace` (add it to the `meta/mode` regex in `database.rules.json`; the owner deploys the rules),
  title **"Derivatives: team race"**, blurb in plain English.
- `teams: { optional: false, sizes: [4], all: false }`. `Live.makeTeams` with size 4 already gives
  8 → 4+4, 7 → 4+3, 6 → 3+3, 5 → 3+2 (checked). With 4 or fewer players there is one team: let it play
  alone (it "wins" when it finishes), and the lobby note suggests the class relay instead. When a team has
  two players, the lobby note says so (one device holds two columns).
- `lateJoin: false`, `autoLock: false`, `noStandings: true`.
- Settings: word set (see §4), words in a run (0 = whole set, 6, 10, 15), seconds frozen for a wrong
  card (0, 3, 5, 8; default 5), prompt card (rotate / always one kind — as the relay).

## 3 · How to build it

- **Reuse the relay's game logic per team.** Export what you need from `derivatives.js`; one game object
  per team. Both teams must deal the SAME sequence: draw the run once (word, which derivative, prompt
  kind for each step) and give it to every team's game (e.g. an `opts.plan`). Decoys may differ.
- **Teams race independently, so use the devices mode's generation counter** (read the header of
  `devices.js`): whenever a team finishes a word, the round is locked and reopened, every hand is
  rewritten (unchanged for the other team), and a tap carries the team's deal parity:
  `v = index + 5 × (deal % 2)`, so **a hand holds at most 5 cards**. Reuse `makeSender` for the
  retry-once-after-reopen behaviour on the device.
- **Hands per team size:** 4 players → the three columns go round the four, one column shared (its 4
  cards split 2+2), moving on each word; 3 → one column each, 4 cards; 2 → one device holds two
  columns, give it 3 + 2 cards (never more than 5), the other device 4.
- **Freeze:** after a wrong card, the host ignores every tap from that team until `frozenUntil`
  (server time, `ctx.now()`); a tap during the freeze is ignored, NOT counted as tried or wrong. The
  public state carries the freeze end so devices count down and disable their cards.
- **The end:** when the first team finishes, it wins: winner banner on the projector and the devices,
  both teams' progress shown, teacher presses Next to the end screen (as devices does).
- **End screen** (`summary`): per team — time to finish (or words done), wrong cards; then the words
  slowest first, per team; then the words with most wrong cards.

## 4 · Two fixes that apply to BOTH derivatives modes (the relay too)

1. **A decoy must never be a second right answer.** `domī` and `domus` share the derivative `domestic`
   (and its definition). Rule: a decoy comes only from a word that shares **no** derivative word and
   **no** derivative definition with the right word, and whose Latin meaning text differs. Test it on
   `i04` with `domestic` as the prompt, many seeds.
2. **"Newest" per class.** The relay's "Newest Trial" takes the last set in the file, which is now a
   Latin I set — wrong for Latin II. Replace it with one "Newest Latin II", "Newest Latin I"… option per
   class present in the file (from each set's `corpus`: `latin-ii` → "Latin II"; value e.g. `newlatinii`,
   letters and digits, 16 at most), then every set by title. Relay default `newlatinii`; race default
   `newlatini`. "Newest" = the last set of that corpus in the file.

## 5 · Screens

- **Projector:** two lanes side by side (they stack on a narrow screen). Each lane: "Team A", its members'
  codenames, "Word 4 of 13" with a progress bar, the prompt card, the three slots (a found card, or
  "… still open" — **never the name of who holds an open slot**, owner 2026-11-02), a frozen banner with
  a countdown, and a short "last match" line. A race clock (time since Start) at the top.
- **Device:** as the relay's device screen, plus the team label, "Word 4 of 13", the other team's word
  number, and while frozen: every card disabled and "Frozen: 4…".
- **Words:** "device", never "phone". Student-facing English is short and plain (English learners): no
  idioms, no jokes that need culture. Labels without "you" (`Your cards` is fine as the relay has it).
- No browser storage (the `live_static` test forbids it); nothing new in the database beyond `state`,
  `hands`, `score`.
